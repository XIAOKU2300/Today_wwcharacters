# 🌸 今日老婆插件

一个基于 Yunzai-Bot 的趣味插件，每天为你随机分配一位二次元老婆，并附带每日一言，让你的聊天机器人更加生动有趣！

## ✨ 功能特色

| 功能 | 描述 |
|------|------|
| 🌸 **每日随机老婆** | 每天固定分配一位二次元角色作为你的"今日老婆" |
| 🎨 **多图展示** | 同一角色有多张图片，每次展示不同的照片 |
| 💫 **每日一言** | 每次附带一句优美的每日一言，提升文艺气息 |
| ⏱️ **智能冷却** | 群聊级别3秒冷却，避免刷屏 |
| 👥 **艾特提醒** | 群聊中自动艾特发起指令的用户 |
| 🗂️ **角色管理** | 支持多个角色文件夹，每个角色有专属图片库 |

## 📥 安装方法

### 1. 放置插件文件
将插件文件 `ceshi.js` 放置到 Yunzai-Bot 的插件目录中：
```bash
# 假设你的 Yunzai-Bot 在 /home/ubuntu/Yunzai-Bot
cp ceshi.js /home/ubuntu/Yunzai-Bot/plugins/example/
```

### 2. 安装依赖
```bash
# 进入 Yunzai-Bot 目录
cd /home/ubuntu/Yunzai-Bot

# 安装 node-fetch
npm install node-fetch
```

### 3. 重启机器人
```bash
# 重启 Yunzai-Bot
npm run stop
npm run start
```

## 📁 目录结构配置

在插件目录下创建 `custom_role_pile` 文件夹，并按照以下结构组织素材：

```
plugins/example/custom_role_pile/
├── 1011/
│   ├── 长离_001.jpg
│   ├── 长离_002.jpg
│   ├── 长离_003.jpg
│   └── 长离_004.jpg
├── 1012/
│   ├── 星瞳_001.jpg
│   ├── 星瞳_002.jpg
│   └── 星瞳_003.jpg
└── 1013/
    ├── 白露_001.jpg
    ├── 白露_002.jpg
    ├── 白露_003.jpg
    └── 白露_004.jpg
```

### 📝 命名规范

- **文件夹命名**：使用数字编号（如：`1011`, `1012`, `1013`）
- **图片文件命名**：`角色名_序号.扩展名`（如：`长离_001.jpg`）
- **支持的图片格式**：JPG、JPEG、PNG、GIF

## 🔧 功能详解

### 🎯 角色分配机制

- **每日固定**：每个用户/群聊每天会随机分配一个固定的角色
- **多图轮换**：同一天内多次请求会看到同一角色的不同图片
- **智能去重**：图片不会重复，直到该角色所有图片都展示过一遍

### ⏰ 冷却机制

| 场景 | 冷却机制 |
|------|----------|
| 群聊 | 同一群内所有用户共享3秒冷却 |
| 私聊 | 每个用户独立3秒冷却 |

### 📚 每日一言功能

- **数据来源**：使用 Hitokoto API 获取优美的句子
- **完整信息**：自动显示句子出处和作者信息
- **容错处理**：如果获取失败，只显示老婆信息

## 🛠️ 自定义配置

### 添加新角色

1. 在 `custom_role_pile` 目录下创建新的数字编号文件夹
2. 在该文件夹中放置角色的图片文件
3. 按照命名规范命名图片文件：`角色名_序号.扩展名`

### 修改冷却时间

如需修改冷却时间，编辑 `ceshi.js` 文件中的冷却检查部分：

```javascript
// 修改这里的 3000 为想要的毫秒数
if (todayWifeCache[cacheKey]?.lastTime && now - todayWifeCache[cacheKey].lastTime < 3000) {
    await e.reply('等等啦，别太快重复请求~ ⏳');
    return true;
}
```

## ❓ 常见问题

### Q: 插件没有响应怎么办？
A: 检查以下项目：
- 插件文件是否放置在正确的目录
- 是否安装了 node-fetch 依赖
- 是否重启了机器人

### Q: 图片发送失败怎么办？
A: 可能的原因：
- 图片文件损坏
- 图片路径错误
- 文件权限问题

### Q: 每日一言不显示怎么办？
A: 这可能是由于 API 暂时不可用，属于正常现象，不影响主要功能。

### Q: 如何添加更多角色？
A: 按照目录结构规范，在 `custom_role_pile` 下创建新的角色文件夹并添加图片即可。
