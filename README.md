# 今日老婆插件 (Daily Waifu)

一个有趣的角色扮演插件，每天为你随机分配专属二次元角色，并附上优美的每日一言。

## 功能特色

✨ **个人专属** - 每个用户每天固定一位角色  
🖼️ **多样展示** - 同一天内可看到同一角色的不同照片  
💝 **每日一言** - 每次附带优美名言佳句  
⏳ **智能冷却** - 3秒个人冷却时间  
👥 **群聊友好** - 自动艾特，体验流畅  

## 安装方法

1. 将 `daily-waifu.js` 插件文件放置到机器人插件目录
2. 安装必要依赖：
   ```bash
   npm install node-fetch
   ```
   使用脚本安装无需执行此步
3. 下载素材包并配置

## 素材配置

1. **下载素材**  
   个人网盘：飞牛分享【custom_role_pile.7z】，点击链接下载文件
   https://s.fnnas.net/s/72f99080f59d42d494
   密码：daily-waifu
   
3. **目录结构**  
   解压后确保目录结构如下：
   ```
   plugins/daily-waifu/custom_role_pile/
   ├── 1011/
   │   ├── 长离_001.jpg
   │   ├── 长离_002.jpg
   │   └── ...
   ├── 1012/
   │   ├── 白露_001.jpg
   │   └── ...
   └── ...
   ```

4. **文件命名**  
   - 文件夹编号对应角色
   - 文件格式：`角色名_编号.jpg`

## 使用方式

在群聊或私聊中发送：
```
#今日老婆
```

## 注意事项

- 每个用户每天首次使用会随机分配角色
- 同一天内重复使用会展示同一角色的不同图片
- 素材需自行从网盘下载，插件不包含图片文件
