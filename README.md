# 今日老婆插件 (Daily Waifu)

适用于TrssYunzai的一个有趣的角色扮演插件，每天为你随机分配专属二次元角色，并附上优美的每日一言。

## 功能特色

✨ **个人专属** - 每个用户每天固定一位角色  
🖼️ **多样展示** - 同一天内可看到同一角色的不同照片  
💝 **每日一言** - 每次附带优美名言佳句  
⏳ **智能冷却** - 3秒个人冷却时间  
👥 **群聊友好** - 自动艾特，体验流畅

## 安装方法

1. 将 `daily-waifu.js` 插件文件放置到机器人插件目录
2. 安装必要依赖：
   ```bash
   npm install node-fetch
   ```
   使用脚本安装无需执行此步
3. 下载素材包并配置

## 素材配置

1. **下载素材**  
   个人网盘：飞牛分享【custom_role_pile.7z】，点击链接下载文件
   https://s.fnnas.net/s/72f99080f59d42d494
   密码：daily-waifu
   
3. **目录结构**  
   解压后确保目录结构如下：
   ```
   plugins/daily-waifu/custom_role_pile/
   ├── 1011/
   │   ├── 长离_001.jpg
   │   ├── 长离_002.jpg
   │   └── ...
   ├── 1012/
   │   ├── 白露_001.jpg
   │   └── ...
   └── ...
   ```

4. **文件命名**  
   - 文件夹编号对应角色
   - 文件格式：`角色名_编号.jpg`

## 使用方式

在群聊或私聊中发送：
```
#今日老婆
```

## 注意事项

- 每个用户每天首次使用会随机分配角色
- 同一天内重复使用会展示同一角色的不同图片
- 素材需自行从网盘下载，插件不包含图片文件

插件逻辑说明
核心工作机制
用户识别

使用用户ID作为唯一标识

群聊和私聊中用户身份保持一致

角色分配逻辑

每天为每个用户随机分配一个角色文件夹

同一用户在同一天内始终看到同一角色

角色文件夹随机选择，确保公平性

图片展示逻辑

记录用户已查看的图片，避免重复

当所有图片都展示过后，重置展示记录

确保用户能看到角色的所有不同图片

缓存系统

用户级缓存：存储用户当天的角色信息

CD缓存：防止用户频繁请求

每日自动重置角色分配

错误处理

素材目录不存在时自动创建并提示

网络请求失败时优雅降级

图片发送失败时友好提示

数据处理流程
text
用户发送 #今日老婆
    ↓
检查用户CD状态
    ↓
检查今日是否已分配角色
    ↓
是 → 从已分配角色中选择新图片
    ↓
否 → 随机选择新角色文件夹
    ↓
获取角色所有图片列表
    ↓
选择未展示过的图片
    ↓
获取每日一言
    ↓
构建并发送消息

跨平台兼容：群聊私聊无缝切换，体验一致

容错机制：多级错误处理，保证服务稳定性
